# Fixed cancellation diagnostic test

The once-only TEST evaluator uses the unchanged 58-column ridge coefficients,
TRAIN-only scaling, and TRAIN kind means from the completed conditional-value diagnostic.
It admits exactly the original prospective origins 224–255, including missing roots and
all offered action siblings. It has no fitting, threshold search, policy export, or game runner.

`CancellationTestProjection` reuses the reviewed native projection audit helpers to replay
only retained prefixes and verify authoritative public cancellation quotes against each
deterministic one-step transition. Its streaming parser skips every outcome tree. The Python
evaluator projects the same actor-safe features and exclusively writes all predictions and
choices before decoding any TEST terminal returns. It selects the highest predicted CANCEL
only when strictly positive, otherwise PASS; positive ties use canonical command order.

The report averages the two shared future streams within each action and weights captured
origins equally. It retains all per-action returns and reports paired first-action reward,
win, rank and Chaos differences versus PASS and the recorded normal incumbent, plus fixed
MSE baselines. Missing origins remain explicit. These small-sample conditional proxies use
the original continuation and fixed hidden world; they are not whole-game strength evidence
and cannot automatically authorize a deployed policy or further experiment.
