# Generic qualified coordinated preview

This source prerequisite adds `aor-coordinated-win-support-1` for future completed, independently
qualified four-head policies. It installs no model, changes no running service and grants no
qualification or activation. The existing `aor-coordinated-83-support-1` asset and its two-metric
qualification remain unchanged.

The portable `coordinated-inference-asset-1` descriptor freezes behavior before qualification:
complete current and original C/P/E/T bundles, their complete dictionaries and unchanged value
parameters, the original V2 E/T calibration, M8/F0/E and packed ordinary references, the current
four-player rules/configuration, Support1, and the incumbent-residual-margin-1 selector. Descriptor
subjects use bounded, confined relative paths and exact raw SHA-256. The descriptor contains no
strength claim. Qualification binds its exact bytes separately to a root-approved nomination;
model hashes and nomination subjects belong to the manifest, not family-specific source constants.

After both fresh 4,096-pair banks pass their independent 99% win-share gates, a final
`coordinated-win-support-preview-1` manifest binds the inference descriptor and its completed
`coordinated-win-qualification-1` certificate. Mixed confirmation precedes the independent
homogeneous bank; a failed confirmation leaves the latter unopened. Rank, terminal reward and Chaos
remain diagnostics. The final manifest hash becomes the stored immutable asset identity. No actual
certificate is created during source verification.

The cached server reader dispatches explicitly by manifest version and reuses the existing model,
reference, calibration and four-head inference owners. It has no training-module dependency and
never replays a training lineage to infer strength. C/P retain their M8/F0 priors, original seeded
sampling and exact Support1 conditioning. E/T retain original-container subtraction, calibrated
scales, margin1 and reference-first ties. The common chooser is unchanged.

The existing local-only configuration, new-seat scope, creator-only proposals, leases and ordinary
command submission remain the execution boundary. Existing saved profile/asset identities cannot
silently rebind to another asset, and missing or mismatched configured assets produce the existing
typed stop. Legacy browser-controlled games and the earlier coordinated profile keep their current
loading, replay and continuation behavior. The current preview and private game data are untouched.

Source verification uses invented model tensors and certificates. It checks both manifest versions,
old reward-gate refusal, generic win-only admission, subject/version mismatch, cached inference,
exact shared-selector commands and saved profile/asset continuity. A shared constructed descriptor
is loaded by native qualification and the server to exercise the transport boundary without a real
nominee, stream, game or strength claim.
