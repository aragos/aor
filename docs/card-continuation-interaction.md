# Expansion acquisition and persistent continuation styles

This isolated research owner compares an offered expansion-card purchase with the actual E command
under five fixed continuations. It changes no playable selector, learned model or existing source
contract. Calibration and collection require separately reviewed frozen inputs before execution.

`CardStyleInteractionInput` admits G3 plus two antithetic pairs of own-seat CARD/PURCHASE output
heads. Each component retains its complete dictionary, 64-unit basis, value head, F0/M8 priors and
sampling. Every rival and every expansion/token overlay remains fixed. The raw calibration receipt
binds each changed component and bundle to the same original G3 reference. It cannot nominate a
style from returns.

`CardStyleInteractionCollector` reuses the exact 72 root schedule and `ExpansionPairedWindow`.
Only the requested branching expansion window in the controlled seat's first assigned-epoch turn
can qualify, and card purchase must actually be offered. All other requests finish their normal
backbone and remain missing. A fresh unchanged controller must reproduce E at the original absolute
PLAYER offset before any tail. The two commands are deduplicated when E itself buys; that world
still contributes its exact zero acquisition difference. Each style persists for the controlled
seat's entire remaining game. Each sibling receives a fresh complete controller map and the same
two future chance starts; original game/absolute-command/seat policy seeds remain unchanged.
Canonical prefix and terminal suffix replay are validation, not extra policy simulations.

The typed entry point is `dev.aragos.aor.training.CardStyleInteractionMain`, with paired options
`--mode prepare|collect --source FILE --output NEW_DIRECTORY`. Collection additionally requires
`--workers` (at most 10) and `--seconds` (at most 7,200). The outer campaign owns the original
absolute deadline, one attempt, JVM/RSS/data limits and cleanup. Preparation invokes no choices or
games. Each worker writes one compressed origin and returns only a compact receipt; completion
checks the entire fixed 1,024-request bank incrementally. Maximum work is 20,480 tails and 1,024
missing terminal backbones. Old card-continuation diagnostics keep their original owners.

## Public calibration boundary

`CardCalibrationPublicMain` is a separate streaming projection of the preselected completed 53
chronological TRAIN batch 32, worlds 0–63. Its source pins the completed batch receipt, original
storage manifest, collection metadata, finished manifest, the path-only terminal export and each
original compressed game. The original batch bundle and portable G3 bundle may have different path
bytes; the export must bind both exact component hashes.
Only the first 32 nonforced observations per phase/world and their original absolute numbers are
decoded. Chosen actions, behavior values/log probabilities, terminal labels and canonical histories
are structurally skipped. The output retains exact game hashes, dictionaries, M8/F0 roles and
counts. Original seeds in the receipt are sampler provenance, never model inputs.

`card_continuation_calibrate.py` admits only the exact qualified G3 heads, fixed public projection
and the audited two direction integers. `card_continuation_calibration.py` shares the unchanged
legacy actor basis and clipped residual/prior probability calculation with `purchase_policy`.
No optimizer is created. For each head/direction, SHA256 coordinate signs form a unit vector;
both signs are retained. The first target crossing on amplitudes 0, 2^-6, …, 2^6 followed by 40
sign-bracket bisections sets equal-world/equal-retained-row mean KL(G3 || variant) to .02 within
1e-6. Unreachable/nonfinite/duplicate directions or fewer 32 represented worlds/256 rows per head
stop preparation without redraw or cohort substitution. All eight scales, row/world KL, TV and
clipping diagnostics remain evidence. Native/JS probability and sample parity must be frozen before
a future scientific launch; this source commit does not authorize real-vector calibration.

## Fixed analysis

The pure report owner retains every sibling and averages the two paired futures within each
world. Four prespecified primary contrasts subtract the G3 buy-minus-E difference from each
variant's difference. Each receives a two-sided 98.75% normal interval, using
`NormalDist.inv_cdf(1 - .05 / 8)`, for Bonferroni family coverage of 95%. Dependence is reported
only if at least one interval excludes zero; no variant is selected. Mean-four, antithetic-pair,
G3 acquisition, win/rank and Chaos summaries are descriptive. Missing worlds are never imputed
zero. A negative interaction can simply mean worse exploitation, and dependence alone establishes
neither a stronger policy nor positive intrinsic card value. No training or runtime admission
follows automatically.
