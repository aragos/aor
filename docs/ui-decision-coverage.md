`BoardGame`, `CardGame`, `PurchaseDecisions`, and `VariantInteractions`, and [canonical commands](commands.md).
A control being present is distinct from a browser interaction passing. “Pending” is an explicit
verification gap, not a claim of completed coverage. Authority outcomes are generated by the server.

`!shuffle`, `!draw`, `!roll`, and `!trade` are authority outcomes, never visual player actions.
Their player-visible effects and secrecy require service and domain checks in addition to browser
coverage; a synthetic component snapshot cannot establish authorization or privacy.

Run `node scripts/browser-check.mjs` from `web` for isolated live browser checks. It builds the server
installation, chooses independent ports, and starts its own server, Vite and Chrome process groups.
It removes temporary game/profile data and terminates every owned process group in `finally`, on
success, failure, timeout, SIGINT or SIGTERM. Screenshots go to a separate temporary artifact directory
printed by the runner; set `AOR_BROWSER_ARTIFACTS` to retain them at a chosen location. Set `CHROME_BIN`
for a different Chrome executable. `AOR_BROWSER_SERVER` may point to an already built server launcher;
it skips the build but still starts and owns a fresh isolated server.
